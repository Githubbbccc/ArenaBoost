## Quick start
- **Easiest:** download `ArenaBoost.exe` from the [Releases](../../releases) page, right-click it and choose **Run as administrator**.
- **From source:** install Python 3.10+ and double-click `RUN.bat`. Double-click `BUILD_EXE.bat` to build the `.exe` yourself.
- **Check it works on your PC:** run `ArenaBoost.exe --selftest`. The report is saved to `%APPDATA%\ArenaBoost\selftest.txt`.

## Screens
- **Dashboard:** a glowing Boost button, live CPU/RAM/disk/network rings, and tips.
- **Games:** Steam, Epic, Riot and emulator games are found automatically. There's search, and double-click to **Boost & Launch**.
- **Monitor:** live usage, the top processes, a RAM purge button and a stutter-cause check.
- **Network:** ping, jitter and packet loss to UAE, Mumbai, Singapore, Europe and the US, plus bandwidth hogs and DNS flush.
- **Settings:** turn each tweak on or off, and edit which apps get paused.
- **About:** version and license.

## What Boost does (all undone automatically)
| Tweak | Why |
|---|---|
| Ultimate/High Performance power plan | The CPU stays at full speed |
| Game priority set to Above Normal | The game gets CPU time first (never Realtime) |
| Pauses browsers, OneDrive, torrents, updaters… | Frees CPU, RAM, disk and **bandwidth**. Apps are paused, not closed. |
| Pauses Windows Update, Delivery Optimization, Search, SysMain, BITS | No background downloads or disk spikes |
| One-time standby RAM purge | The same method ISLC uses |
| 0.5 ms timer resolution | Smoother frame pacing |
