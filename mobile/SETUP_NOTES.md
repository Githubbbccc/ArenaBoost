# ArenaBoost Mobile – Build
This folder is a complete Flutter project. Nothing needs to be copied in.
```
flutter pub get
flutter test                 # 12 tests
flutter run                  # run on a connected phone
flutter build apk --release  # APK -> build/app/outputs/flutter-apk/
flutter build ios --release  # needs a Mac with Xcode + Apple signing
```
Native Android code: `android/app/src/main/kotlin/com/arena/arenaboost/MainActivity.kt`
